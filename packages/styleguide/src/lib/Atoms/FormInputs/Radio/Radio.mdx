## Usage

Radio allows single selection within a group of options. Use RadioGroup to group multiple Radio components together semantically.

Our Radios are [controlled components](https://reactjs.org/docs/forms.html#controlled-components), so their checked value must be controlled by an external state and `onChange`. RadioGroup forwards `name` and `onChange` to every Radio so they are semantically linked and mutually exclusive. For example:

<Canvas of={RadioStories.RadioGroupComponent} />

```tsx
import { Radio, RadioGroup } from '@codecademy/gamut';
import React, { ChangeEvent, useState } from 'react';

const RadioGroupComponent = () => {
  const [selected, setSelected] = useState('option-1');

  const changeHandler = (event: ChangeEvent<HTMLInputElement>) => {
    setSelected(event.target.value);
  };

  return (
    <RadioGroup
      htmlForPrefix="example-radio"
      name="example-radio"
      onChange={changeHandler}
    >
      <Radio
        checked={selected === 'option-1'}
        label="Option 1"
        value="option-1"
      />
      <Radio
        checked={selected === 'option-2'}
        label="Option 2"
        value="option-2"
      />
    </RadioGroup>
  );
};
```

RadioGroup can also be used within ConnectedForm via <LinkTo id="Organisms/ConnectedForm/ConnectedFormInputs">`ConnectedRadioGroupInput`</LinkTo> and GridForm via <LinkTo id="Organisms/GridForm/Fields">`GridFormRadioGroupInput`</LinkTo>, which wire up the checked value and `onChange` for you.

## Custom labels + InfoTip

The `label` is a `ReactNode`, making it customizable outside of a standard text label. If you are including an <LinkTo id="Molecules/Tips/InfoTip">`InfoTip`</LinkTo>, you should include it as the infotip prop to ensure it isn't repeated by screen readers.

<Canvas of={RadioStories.CustomLabel} />

## RadioGroup with InfoTip

You can add an InfoTip to a RadioGroup label by wrapping the `RadioGroup` with a `FormGroup` and passing the `infotip` prop. The InfoTip will be automatically linked to the RadioGroup label via `aria-labelledby` for accessibility.

Individual Radio options can also have their own InfoTips, which are automatically linked to their respective labels.
