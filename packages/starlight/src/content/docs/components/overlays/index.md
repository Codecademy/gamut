Things a user explicitly opens and dismisses, floating above the rest of the page.

- [Modal](/components/overlays/modal/), [Dialog](/components/overlays/dialog/), [Overlay](/components/overlays/overlay/)
- [Popover](/components/overlays/popover/), [PopoverContainer](/components/overlays/popover-container/)
- [Flyout](/components/overlays/flyout/)

Flyout lives here because it floats above the page, unlike [Drawer](/components/containers/drawer/), which collapses within page flow — see Containers for that. Tooltips and other explanatory hovercards live in [Tips](/components/feedback/tips/) under Feedback, not here.
