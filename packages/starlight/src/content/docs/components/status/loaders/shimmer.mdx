## Usage

Use `Shimmer` to preview the shape of content that's still loading. It accepts any `Box` prop (`height`, `width`, `bg`, spacing, and so on), so it can be sized and positioned like the content it's standing in for.

**Best practices:**

- `Shimmer` takes only standard `Box`/system props — there's no dedicated `shape`, `count`, or line-based skeleton API. Compose several `Shimmer`s, each sized to match a piece of real content, to build a multi-line placeholder.
- Its gradient adapts automatically to light and dark ColorMode.

**When NOT to use:**

- **A known amount of progress** — use [ProgressBar](/components/status/progress-bar/) or [RadialProgress](/components/status/radial-progress/) instead.
- **A small, compact loading indicator inside an already-loaded component** — use [Spinner](/components/status/loaders/spinner/) instead.
