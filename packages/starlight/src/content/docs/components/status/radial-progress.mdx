## Usage

Use `RadialProgress` to display progress as a percentage of a whole, as a ring instead of a linear bar.

**Best practices:**

- Pass `children` to show a label — a percentage or an X/Y ratio — centered inside the ring.
- Pass `value` as a `[start, end]` tuple together with `duration` (in ms) to animate smoothly between two values on render, instead of jumping straight to the end value.
- Unlike [ProgressBar](/components/status/progress-bar/), `RadialProgress`'s progress label isn't in a live region. If its value updates after the initial render, pair it with your own live-region announcement so screen reader users learn about the change.

**When NOT to use:**

- **A horizontal bar instead of a ring** — use [ProgressBar](/components/status/progress-bar/) instead.
- **Indeterminate loading, with no known amount of progress** — use [Spinner](/components/status/loaders/spinner/) or [Shimmer](/components/status/loaders/shimmer/) instead.
