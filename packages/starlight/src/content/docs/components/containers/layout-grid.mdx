## Usage

Use `LayoutGrid` to build a flexible grid for full-page layouts. Any row of content snaps to 12 units of width; each cell is a `Column` with a grid-specified gap to its neighbors. Row and column gaps can be set responsively — a different gap at small viewports than at large ones.

**Best practices:**

- Use `LayoutGrid` for full-page layouts, not for containing smaller areas of a page.
- Keep row height consistent across a grid when using `rowspan`, so spanned columns line up cleanly.

**When NOT to use:**

- **Containing a smaller area of the page** — use a [Box](/components/containers/boxes/box/), [FlexBox](/components/containers/boxes/flex-box/), or [GridBox](/components/containers/boxes/grid-box/) instead.
