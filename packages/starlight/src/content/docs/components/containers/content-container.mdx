## Usage

Use `ContentContainer` when building a page layout, to contain content within a maximum width, center it, and get responsive horizontal padding that matches Gamut's grid system.

**Best practices:**

- Use it for full-page layouts, not for containing smaller areas of a page.

**When NOT to use:**

- **Containing a smaller area of the page** — use a [Box](/components/containers/boxes/box/), [FlexBox](/components/containers/boxes/flex-box/), or [GridBox](/components/containers/boxes/grid-box/) instead.
