## Usage

Use `Select` for single selection within a group of options, backed by a native `<select>` element.

**When NOT to use:**

- **Rich option content, multi-select, search, or creatable options** — use [SelectDropdown](/components/inputs-and-forms/select-dropdown/) instead; `Select` only supports plain text options and native browser dropdown behavior.
- **A small, always-visible set of options** — use [Radio](/components/inputs-and-forms/radio/) instead.
