## Figma Make

Designers: use the published Gamut Make kit in Figma when building in Make — add it from the org kit picker inside the Figma app; kits aren't configured via a local CLI. See Figma's [guide to Make kits](https://help.figma.com/hc/en-us/articles/39241689698839) for how kits work.

Maintainers update the published kit directly in Figma, uploading or editing guidelines in the Make file's code explorer — see [Add guidelines to Figma Make](https://help.figma.com/hc/en-us/articles/33665861260823). Engineers should use Storybook and the Gamut plugin skills for implementation reference instead.
