# Migrating to logical properties

<Callout type="default">
  **How-to.** Goal: an existing screen that still looks correct when rendered
  `dir="rtl"`.
</Callout>

Gamut's `useLogicalProperties` theme flag swaps physical properties
(`margin-left`, `border-right`, …) for their logical equivalents
(`margin-inline-start`, `border-inline-end`, …) so layouts mirror
correctly under RTL locales. Turning it on can surface places where a
screen assumed a physical direction.
