# Supporting dark mode

<Callout type="default">
  **How-to.** Goal: a screen that looks correct in both light and dark mode
  without hardcoded colors.
</Callout>

Use semantic color aliases (`text`, `background`, `border-primary`, …)
rather than hex values or palette names — aliases resolve to different
concrete colors per mode automatically. Reach for `Background` when a
surface needs an explicit contrast-safe container.
