# Building forms

<Callout type="default">
  **How-to.** Goal: a working, accessible form with validation.
</Callout>

For most forms, reach for `ConnectedForm` + `ConnectedFormGroup`, which
wire [react-hook-form](https://react-hook-form.com/) registration,
labels, and accessible error regions together. Reach for the lower-level
`Form` / `FormGroup` scaffolding only when you need control the
connected components don't give you.
