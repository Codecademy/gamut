# Contributing to Gamut

<Callout type="default">
  **How-to.** Goal: get a change into `@codecademy/gamut` (or a sibling package)
  merged.
</Callout>

Gamut is an Nx/Yarn-workspaces monorepo under `packages/*`. Component
source lives in `packages/gamut/src`; run `yarn start` to develop
against the Storybook-based styleguide, `yarn verify` before opening a
PR, and `yarn build` to confirm every workspace package still builds.
