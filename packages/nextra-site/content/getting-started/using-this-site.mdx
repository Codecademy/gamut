# Using this site

<Callout type="default">
  **Tutorial.** How to read this site, not how to use Gamut itself.
</Callout>

This site follows the [Diátaxis framework](https://diataxis.fr): each
top-level section serves one reader need.

- **Getting started** — learning-oriented. Read top to bottom the first
  time.
- **Guides** — goal-oriented. Jump straight to the task you're doing.
- **Components** — reference, grouped by what a component does (Actions,
  Containers, Feedback, …) rather than by Gamut's internal Atomic
  Design tiers. If you know a component's name, use search instead of
  browsing.
- **Reference** — fact-lookup: tokens, themes, system props, tooling.
- **Concepts** — understanding-oriented: the rationale behind the
  system.

Every component page follows one fixed template — Usage, Patterns,
Variants, Accessibility, Props, Playground, in that order — so once you
know the template, every component page is navigable the same way.
