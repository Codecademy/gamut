# System props

<Callout type="default">
  **Reference.** Which system prop group covers which CSS property.
</Callout>

Gamut components accept style props composed via `variance.compose()`
into groups like `system.layout`, `system.positioning`, `system.space`,
and `system.border` — each button on this site's Playgrounds, for
example, is built on `system.space` + `system.border` + `system.layout`

- `system.positioning`.
