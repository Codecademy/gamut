# Themes

<Callout type="default">**Reference.** The available themes, by name.</Callout>

`@codecademy/gamut-styles` exports five themes: `coreTheme`,
`platformTheme`, `adminTheme`, `lxStudioTheme`, `percipioTheme`. Each
pairs with `GamutProvider` — see
[Guides → Theming your app](/guides/theming-your-app).
