# Icon catalog

<Callout type="default">
  **Reference.** Every icon, by name, searchable.
</Callout>

`@codecademy/gamut-icons` exports two families: Regular icons (larger,
standalone) and Mini icons (16px, meant to sit inline with text — e.g.
the `icon` prop on
[FillButton](/components/actions/fill-button#playground)).
