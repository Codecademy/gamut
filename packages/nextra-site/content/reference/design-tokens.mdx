# Design tokens

<Callout type="default">
  **Reference.** Token values, by name. For the reasoning behind the token
  system, see [Concepts → Theming model](/concepts/theming-model).
</Callout>

Tokens are exposed as semantic aliases (`text`, `background`,
`border-primary`, `primary`, …) rather than raw values, so the same
name resolves to a different concrete value per theme and color mode.
