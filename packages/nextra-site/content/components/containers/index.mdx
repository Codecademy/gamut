# Containers

Components that group or lay out other content: `Box`, `FlexBox`,
`GridBox`, `Card`, `ContentContainer`, `LayoutGrid`, `Disclosure`,
`Drawer`.

`Drawer` lives here rather than in Overlays: it collapses within page
flow, unlike `Flyout`, which floats above it.
