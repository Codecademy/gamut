# Inputs & forms

Components that collect input:

- Fields — `Input`, `TextArea`, `Checkbox`, `Radio`, `Toggle`,
  `Select`, `SelectDropdown`, `DatePicker`.
- Form scaffolding — `Form`, `FormGroup`, `FormGroupLabel`,
  `FormGroupDescription`, `FormRequiredText`.
- Connected forms — `ConnectedForm`, `ConnectedFormGroup`,
  `ConnectedFormInputs`, `SubmitButton` (wires
  [react-hook-form](https://react-hook-form.com/) for you; see
  [Guides → Building forms](/guides/building-forms)).
- `GridForm` — a grid-aligned form layout. Large enough that it may
  split into per-mode child pages once migrated (ADR 0001 §3).
