# Navigation

Components that move someone between pages or sections: `Anchor`,
`Breadcrumbs`, `Pagination`, `Tabs`, `SkipToContent`.

`Anchor` lives here rather than in Typography: it's functionally
navigation despite being implemented as styled text. `Menu`'s
navigation-list role is cross-linked from
[Actions](/components/actions), where its richer action-list role is
documented.
