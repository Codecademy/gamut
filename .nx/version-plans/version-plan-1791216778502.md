Move Video out of barrel and update

- `Video` is now imported from `@codecademy/gamut/Video` instead of `@codecademy/gamut`.
- `@vidstack/react` and `react-player` are now optional peer dependencies. If you use `Video` (or the Markdown `Iframe`/`MarkdownVideo` overrides), install them: `yarn add @vidstack/react react-player`.
